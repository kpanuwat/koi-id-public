# Code of conduct / จรรยาบรรณ

This project follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good intent, no harassment. Report problems privately to the maintainers through
GitHub (see SECURITY.md for the private reporting channel). Maintainers may remove content or contributors that
break these rules.
โครงการนี้ใช้ Contributor Covenant 2.1: ให้เกียรติกัน ไม่คุกคาม แจ้งปัญหาเป็นการส่วนตัวกับผู้ดูแลผ่าน GitHub
